## ✨ Features

- **🎨 Pastel UI Design:** A consistent, soft, and modern look using custom CSS variables.
- **📱 Fully Responsive:** Optimized layout for Desktop, Tablet, and Mobile devices.
- **📩 Working Contact Form:** Integrated with **EmailJS** to send messages directly to your email without a backend server.
- **🖼️ Project Gallery:** Includes a custom slider and a **Lightbox (Zoom)** feature to view project details clearly.
- **⚡ Fast Performance:** Powered by Vite for lightning-fast development and build times.
- **💅 Modern Animations:** Smooth transitions and hover effects using CSS3.

---

## 🛠️ Tech Stack

- **Frontend:** React JS (Hooks & Functional Components)
- **Build Tool:** Vite
- **Styling:** Bootstrap 5 & Custom CSS (Pastel Theme)
- **Icons:** React Icons / Flaticon / DevIcon
- **Form Handling:** EmailJS
- **Deployment:** GitHub Pages / Vercel (Recommended)
